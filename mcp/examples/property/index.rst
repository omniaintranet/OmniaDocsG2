Enterprise properties
=====================

Enterprise properties are the tenant-wide metadata fields Omnia uses everywhere - the fields on a page, the columns you filter a rollup by, the values a search category can refine on. The connector can read them, create new ones and change existing ones, and it can list the property sets that group them.

This is tenant administration. Everything on these pages needs tenant scope and the permission to manage enterprise properties.
