Languages
=========

Omnia content and interface texts follow the languages enabled for the tenant, and a business profile can either inherit those languages or keep its own shorter list. The connector can read and change both levels.

Enabling a language matters beyond the interface: a multilingual title or description - on an announcement, a link, a page type - can only carry values for languages that are actually enabled.
